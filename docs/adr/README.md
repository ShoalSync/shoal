# Architecture decisions

Each record captures one decision: its context, what was decided and the consequences. Records
are numbered in order and never renumbered; a changed decision gets a new record that
supersedes the old one.

To propose a decision, copy [0000-template.md](0000-template.md) to the next free number and
open a pull request. Add it to `docs/SUMMARY.md` in the same pull request.
