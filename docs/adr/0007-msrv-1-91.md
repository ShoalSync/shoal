# 0007: Minimum supported Rust version 1.91

- Status: accepted
- Date: 2026-09-23

## Context

The initial MSRV was 1.85. Phase 2 builds on iroh 1.x and iroh-blobs, which both declare
`rust-version = "1.91"`. Older iroh releases that support 1.85 are pre-1.0 with an API that has
since been replaced. The 1.85 floor had also held `fastcdc` back at 3.x.

## Decision

Raise the MSRV to 1.91 (`workspace.package.rust-version`). The CI MSRV job builds on 1.91.

Policy from here: the MSRV may move to whatever our direct dependencies require, but never to a
Rust release less than six weeks old, and each bump is recorded by updating this ADR or
superseding it.

## Consequences

- iroh 1.x and current iroh-blobs are usable.
- `fastcdc` can move to 5.x. Its v2020 cut points are unchanged, so manifests stay the same.
- Distributions shipping Rust older than 1.91 cannot build Tidefell from source.
