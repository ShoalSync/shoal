Shoal 0.24.0 is the first public release of Shoal Sync: open-source, peer-to-peer file sync
with no central server. The versions before it were developed privately under another name,
and none of them was ever published.

## A clean break from the private versions

- The programs are `shoal`, `shoald`, the Windows tray app and its installer; the crates are
  `shoal-*`, and the Android app is `org.shoalsync.android`.
- **Not compatible with the private versions, 0.23.x and earlier.** The protocols, the on-disk
  state and the key derivations all changed: a 0.24.0 device does not connect to one of them
  and does not read their state.
- **If you ran one of them,** set each device up again: `shoald init` on the first device, pair
  the others, then create and join the folders again. Your files are not touched; point the new
  folders at them. Remove the old data directory once you have moved over.

## Verifying a download

Every asset has a `.sha256` file and a Sigstore bundle, `.sigstore.json`. Releases are signed
without a long-lived key, by the release workflow's own GitHub identity, and the signature is
recorded in Sigstore's public log. With [cosign](https://docs.sigstore.dev/cosign/system_config/installation/):

```sh
version=0.24.0
target=x86_64-unknown-linux-gnu   # or the asset you downloaded
cosign verify-blob shoal-$version-$target.tar.gz \
  --bundle shoal-$version-$target.tar.gz.sigstore.json \
  --certificate-identity "https://github.com/ShoalSync/shoal/.github/workflows/release.yml@refs/tags/v$version" \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
```

The [install guide](https://github.com/ShoalSync/shoal/blob/main/docs/guide/install.md)
has the details.

## Also in this release

- On Windows, a file pinned with "Always keep on this device", or through Shoal, is now
  downloaded even on Windows editions that do not do this themselves, as Windows Server 2025
  and Windows 11 Enterprise do not.
- A restart could fail a folder change made right after it, when the engine that had just
  stopped still saved its settings.
- Releases are built and signed on GitHub's hosted runners (ADR 0045).
